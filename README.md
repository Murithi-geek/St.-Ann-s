# School Website

This project is a simple school website consisting of multiple pages that provide information about the school, a gallery, contact details, and links to external resources.

## Project Structure

- **index.html**: The home page of the website featuring a navigation bar and a cover background image.
- **about.html**: Contains three images aligned to the left of paragraphs describing different aspects of the school.
- **gallery.html**: Redirects users to the school's Instagram account.
- **contact-us.html**: Features a contact form for users to submit their name, email, and comments, which are sent to "roymworia@gmail.com". It also displays the school's contact details.
- **chapel.html**: Redirects users to the chapel website.
- **css/styles.css**: Contains the CSS styles for the website, including styles for the navigation bar and layout.
- **images/**: A folder designated for storing images used throughout the website.

## Setup Instructions

1. Clone the repository to your local machine.
2. Open the `index.html` file in a web browser to view the home page.
3. Navigate through the website using the navigation bar to explore other pages.

## Features

- Responsive navigation bar with a sky blue background and white text that changes to navy blue on hover.
- Consistent cover background image across all pages.
- Contact form that sends submissions directly to the specified email.
- Links to external resources for the gallery and chapel pages.

## Usage

Feel free to modify the content and styles as needed to better fit your school's branding and information.
